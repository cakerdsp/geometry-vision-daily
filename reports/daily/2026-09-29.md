## 科研趋势综合分析

### 今日主要趋势

1. **几何基础模型从“单模态前馈”走向“异构输入与效率友好”**
   代表论文：MEOW（2609.35658，混合相机前馈重建）、ReSS（2609.35593，3D ViT 稀疏注意力）、3D Point Tracking with State Space Models（2609.34035）。
   三条线索指向同一方向：几何基础模型不再只服务于“标准透视 + 均匀视图”输入。MEOW 把透视/鱼眼/全景统一到一次前向重建，强调数据适配而非架构重设计；ReSS 针对 VGGT 类模型的全局注意力瓶颈，把稀疏化判据从注意力概率改为残差流漂移；3D 点追踪则用冻结前端 + Mamba 状态空间模型控制内存。三者共同说明几何基础模型正进入“输入异构化 + 计算可控化”的第二阶段。

2. **视频生成先验与几何隐空间/扩散模型的耦合成为新视角合成主流路线**
   代表论文：GeoVerse（2609.35734）、GenNVS（2609.34579）。
   两者都把视频扩散模型当作外观先验来源，但约束方式不同：GeoVerse 在预训练 3D 基础模型的几何隐空间内生成，并用 ControlNet 风格适配器注入 Wan2.2 VACE 特征，再用全局空间记忆锚定跨视角一致性；GenNVS 则用解耦的前景/背景 3DGS 对齐成统一场景，再以 Dual-Stream Masking 条件化视频扩散。共同趋势是：不再直接让扩散模型在图像空间自由生成，而是先用显式或隐式几何结构“约束生成空间”。

3. **主动/自适应视图与基元分配：从“多视图堆算力”转向“选择性信息获取”**
   代表论文：Less Is More（2609.35573）、AGILE-GS（2609.34176）、Rate-Distortion Adaptive Primitive Selection（2609.34367）。
   这三篇分别处理输入视图选择（无渲染视图选择器 + 遗传算法蒸馏）、下一最佳视角选择（虚拟锚点 + 候选短名单）、基元分配（HEALPix 网格 + 球面率失真目标）。共同点是：都承认“更多视图/更多基元不等于更好”，把问题重构为信息增益、冗余度与编码代价的联合优化，并强调推理时低成本（无渲染、无 Fisher 全池计算、无固定基元预算）。

4. **3DGS 正从“渲染表示”扩展为可查询、可规划、可编码的通用场景接口**
   代表论文：CollisionSplatting（2609.35619）、EviSplat（2609.34853）、RoGSW4RLD（2609.35311）、SurgGMF（2609.34733）、OIC-GS（2609.34367）。
   方向差异明显但共享底层假设：3DGS 场景可以承载非渲染任务。CollisionSplatting 直接在 3DGS 上定义可调保守度的碰撞距离度量，接入 MPPI/RRT；EviSplat 保留每观测特征作为开放词汇分割的“证据”；RoGSW4RLD 把多相机世界模型 rollout 提升为可跨视角/时间查询的 4D 高斯场；SurgGMF 在高斯运动场上做因果预测；OIC-GS 把高斯基元做成可分层传输、可视口解码的编解码器。

5. **具身智能与机器人方向强调“统一动作/场景表示 + 仿真到现实的中间层”**
   代表论文：UMR（2609.34256）、DexAgent（2609.35318）、RoGSW4RLD（2609.35311）、Terrain-Aware Planetary Exploration（2609.35493）、MarsLab（2609.34702）。
   UMR 把操作分解为本体无关的 World Flow 与 Ego Trajectory，实例化为 0.5B 的 WEPVLA，目标是人类演示到异构机器人的零样本迁移；DexAgent 用智能体式 Human2Sim2Robot 流程与自进化工具库处理铰接/可变形物体；RoGSW4RLD 为机器人世界模型提供统一 4D 查询场；后两篇则提供行星探索的地形感知框架与 ROS2 原生仿真器。共同趋势：具身智能不再只追求端到端策略，而是在动作表示、场景表示、仿真基础设施三个层面同时建“中间层”。


### 技术路线观察

- **几何基础模型**：MEOW 走“保留透视预训练骨干 + 程序化数据引擎覆盖连续相机流形”的数据适配路线；ReSS 走“块级稀疏注意力 + 残差流漂移判据”的推理效率路线；3D 点追踪走“冻结 2D 光流与度量深度前端 + Mamba 残差学习”的组合路线。三者都不倾向于重新训练一个巨型端到端模型，而是在已有基础模型上做输入适配、注意力稀疏化或模块组合。

- **3D/4D 重建**：MEOW 与 ReSS 关注前馈重建/位姿预测的输入异构性与计算效率；RoGSW4RLD 关注把世界模型的多相机视频预测提升为统一度量 4D 场，强调跨视角一致性；VideoPhysEdit（2609.35134）则把刚体物理场景重建用于反事实视频编辑，重建在这里是物理推理的显式中间表示；3D 点追踪把度量深度作为核心瓶颈，用状态空间模型处理长轨迹。

- **神经场景表示**：3DGS 是今日最集中的表示载体。GeoVerse 与 GenNVS 把 3DGS/几何隐空间作为扩散生成的条件；CollisionSplatting 把 3DGS 当作规划代价的查询结构；EviSplat 把 3DGS 当作开放词汇分割的证据容器；SurgGMF 把高斯运动场当作预测对象；OIC-GS 把高斯基元当作可编码、可分层传输的码流单元。趋势是 3DGS 的“可微渲染表示”定位正在被更通用的“场景查询与操作接口”定位补充。

- **机器人/AR 应用**：CollisionSplatting 把 3DGS 接入 MPPI/RRT，属于规划层；RoGSW4RLD 把世界模型 rollout 空间化，属于世界模型层；UMR 与 DexAgent 属于策略与数据生成层；Terrain-Aware Planetary Exploration 与 MarsLab 属于感知建图与仿真基础设施层。整体上，机器人方向对 3D 表示的消费方式分化为“直接用几何做规划”“用 4D 场查询未来”“用统一动作表示做跨本体迁移”“用仿真器做算法基准”四条路径。
