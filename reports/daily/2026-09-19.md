## 科研趋势综合分析

### 今日主要趋势

1. **高斯泼溅从“离线重建”向“在线/持续/资源受限系统”迁移。**
   本窗口内多篇论文不再把 3DGS 视为离线新视角合成工具，而是嵌入到持续运行、算力受限、传感器不理想的系统中：`EliGSiR` 处理在线 RGB-D 连续建图并控制优化预算，`RawSLAM` 直接在 16 位线性 HDR 上在线跟踪与建图，`VGGT-GS SLAM` 面向未标定视频，`SLAMSqueezeBench` 则专门评估资源约束下的 SLAM 对比。这一组共同指向“3DGS + SLAM + 边缘部署”的工程化收敛。

2. **前馈几何先验成为重建系统的“初始化与约束来源”，而非端到端替代品。**
   `GRF-Recon` 用 LoRA 把单目几何线索蒸馏进前馈主干并使用射线场优化，`VGGT-GS SLAM` 明确以 VGGT 位姿/深度先验为起点再做子图可微 BA，`PhGS` 选择冻结前馈模型、在后处理阶段剪枝与精修。三者反映的路线是：前馈模型负责给出粗解或先验，传统优化/后处理负责恢复精度与紧凑性，而不是二选一。

3. **物理/触觉/本体感觉等“非视觉模态”被引入世界模型与场景理解。**
   `DexTouch-WM` 用人类触摸数据监督机器人触觉世界模型，`Feel-WM` 首次把本体感觉作为越野导航世界模型的条件输入，`SnapPhysics` 从单图估计质量、摩擦、重心并构建物理感知场景图。趋势是从“预测画面”走向“预测交互后果”，视觉几何与物理属性开始被联合建模。

4. **单视图/少视图的“多解性”与表示冗余被正面处理，而非强行收敛到唯一解。**
   `Printing the Underdetermined` 明确把绘画重建的 multi-solutionness 作为对象保留并实体化，`PhGS` 针对单视图前馈 3DGS 的射线级冗余做后处理压缩，`GS-PI` 把 PBR 材质生成解耦为 3D 点云扩散以避免联合优化歧义。这反映出社区对病态逆问题的态度变化：显式承认不确定性并设计表示来表达它。

5. **具身与农业/水下/自动驾驶等垂直场景推动“语义 + 几何 + 控制”一体化。**
   `Semantic SLAM in Precision Agriculture` 把贝叶斯语义建图与 g²o 图优化结合，`Underwater Visual Target Tracking` 把目标特定深度估计与自适应 MPC 耦合，`CoRef-GS` 做多机融合地图上的指代式定位，`AnyViewDex`/`VABench` 关注视角不变操作与空间智能评测。应用侧需求正在反向定义重建与表示的评价标准。

### 技术路线观察

- **几何基础模型（Geometry Foundation Models）：** 本窗口只有 `GRF-Recon` 和 `VGGT-GS SLAM` 明确归属此类。两者共同点是“前馈先验 + 显式优化”的混合范式：前者用 LoRA 注入单目几何线索并做稀疏射线场优化，后者用 VGGT 先验做子图 BA 与尺度精化。可以看出该方向当前的重心不在扩大模型本身，而在如何把基础模型输出稳定地接入长序列、未标定、全局一致的系统。

- **3D/4D 重建与多视图几何：** `SplashSplat` 用逐帧液体 SDF、水平集传输和拉格朗日载体处理极端动态的飞溅液体，是 4D 动态重建中少见的真实数据驱动工作；`Underwater Visual Target Tracking`、`Semantic SLAM`、`RawSLAM`、`SLAMSqueezeBench` 则把多视图几何放在水下、农田、HDR、边缘算力等非理想条件下考察。整体侧重是“非受控真实场景 + 鲁棒性 + 实时性”。

- **神经场景表示与渲染：** 3DGS 仍是绝对主流，但研究焦点明显分化：`GS-PI` 做可重光照 PBR 资产，`PhGS` 做单视图表示压缩，`CoRef-GS` 做多机语义融合，`Printing the Underdetermined` 用 Gaussian 密度光晕与鬼影显式表达不确定性，`GAPrompt++` 则把 PEFT/提示学习引入点云 3D 视觉模型。表示层面的问题从“如何渲染得更真”转向“如何可编辑、可压缩、可协作、可表达歧义”。

- **机器人/AR 应用：** `DexTouch-WM`、`AnyViewDex`、`Feel-WM`、`VABench`、`SnapPhysics`、`AURORA`、`VAST` 覆盖触觉世界模型、视角不变操作、越野导航、空间智能评测、MR 物理属性、空地协同仿真验证。技术侧重点是降低对显式 3D 传感/标定的依赖（AnyViewDex、DexTouch-WM），以及把语言/物理/控制纳入统一表示（SnapPhysics、AURORA、VAST）。

### 值得优先阅读的论文

1. **SplashSplat**：真实多视角飞溅液体数据集本身可能是本窗口最稀缺的贡献，且“仅在观测可约束处施加物理结构”这一原则对动态流体、可变形物体等 4D 重建问题具有方法论迁移价值。适合关注动态场景表示与物理先验结合的研究者。

2. **GRF-Recon**：长单目序列的前馈重建是当前几何基础模型落地的主要瓶颈之一，其“粗到细轨迹对齐 + LoRA 几何先验注入 + 稀疏射线场优化”组合具有较高的可复用性，且给出了显存、局部几何、轨迹漂移三类问题的统一应对。

3. **EliGSiR 与 RawSLAM 二选一（或同读）**：如果关注在线 3DGS 系统，`EliGSiR` 的预算控制与视图调度机制对持续建图很关键；如果关注传感器域与光照鲁棒性，`RawSLAM` 的 HDR 高斯 SLAM 更具新意。两者都代表 3DGS 从离线走向在线运行的核心工程问题。

4. **Feel-WM**：把本体感觉引入导航世界模型是对“世界模型只预测视觉未来”这一默认假设的直接挑战，且失败风险从自身经验学习、无需人工标注，思路简洁、可扩展性强，适合具身智能方向。

5. **VABench**：作为评测工作，它把“观察—推理—行动—修正”闭环和主动视角选择纳入空间智能评估，且明确排除特权位姿与 oracle 轨迹。对想了解当前 MLLM 在具身空间任务上真实短板的研究者，这是高信息密度的入口。

### 可能的研究机会

- **把 SplashSplat 的“按可约束性施加物理结构”原则推广到其他病态动态场景**：例如烟雾、布料撕裂、颗粒流。当前其物理结构仅用于液体 SDF 与速度场，是否可以与 `GS-PI` 的 3D 扩散先验或 `Printing the Underdetermined` 的多解采样结合，形成“观测约束内确定性、约束外多解采样”的统一框架。

- **前馈先验与在线持续建图的结合尚不充分**：`GRF-Recon` 和 `VGGT-GS SLAM` 都用了前馈先验，但 `EliGSiR` 这类持续建图仍未显式利用基础模型先验。一个自然方向是：在预算受限的持续 RGB-D 建图中，用前馈几何模型做视图调度与几何增长决策，把算力花在最不确定的区域。
