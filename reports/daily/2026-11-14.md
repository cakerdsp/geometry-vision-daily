## 科研趋势综合分析

### 今日主要趋势

1. **"效率—质量"重构成为视图合成与渲染的主线矛盾。** TTB 针对 decoder-only 视图合成模型的推理效率，用"烘焙"把跨视图注意力映射进轻量 MLP；MatrixSplat 则从 GPU 执行层面把 3DGS 的顺序依赖 alpha 合成改写为矩阵并行累加，以支撑高维特征渲染。两者都指向同一个现实：现有神经渲染的瓶颈已从"能否重建"转向"能否以可部署的成本重建高质量场景"。EG360 在嵌入式端（Jetson Orin NX, 35 FPS）追求零样本泛化的轻量全景深度，也是这条主线在深度估计上的延伸。

2. **3D/4D 重建开始显式处理"非理想观测"。** 一批论文不再假设干净、稠密、有位姿的输入：ReCan-GS 用形变场 Jacobian 自动分离干扰物与有效动态内容；Topo-4DGS 针对第一人称视频中的分裂/合并/开闭等拓扑变化，动态激活或停用高斯；ThermalSplat 处理热红外无位姿、稀疏视图、无 RGB 引导的重建；Track4D 在训练数据稀缺下复用视频扩散模型做稠密 3D 跟踪。共同点是把"数据缺陷"或"表示失效"当作一等公民建模，而非用更强先验硬压。

3. **几何基础模型走向"系统化 + 自监督闭环"。** Kosmo-GFM 将几何基础模型（GFM）、位姿优化引擎（PoseEngine）与重建派生监督（KosmoWorld）整合为生产级系统，并用 3D/4D Gaussian Splatting 作为下游验证接口。这与此前多篇单独做深度/位姿预测的路线不同，信号是：几何预测正在被包装成可插拔的"引擎"，并以重建质量作为最终训练信号。Multi-View 3D Reconstruction Using V-JEPA Features 则提供了反面/审慎证据——空间相机回归降低了绝对轨迹误差 29.3%，但差于 identity poses，且深度误差反而更差，说明"更强特征"未必自动转化为更好几何。

4. **机器人感知从"隐式推断"转向"显式空间/运动学量"。** MOSAIC 在预训练 VLA 主干上注入目标/目标区/障碍物的角色掩码与几何 token；VOKE 在位姿估计器上补出线/角速度与加速度；VINE 把外置相机观测转成视角不变障碍图再交给 PPO 或 A*；RUMI 用匹配 Robotiq 2F-85 的手持接口采集力感知数据。这一组工作共同指向：下游控制器不应从 2D 视觉里"猜"几何、动力学和力，而应由感知端显式输出。

5. **数据/基准建设与部署侧剖析并行推进。** Spatial Foundry（5,280 个带家具住宅 3D 场景，共享坐标、多模态对齐、可编辑）与 TopoEgo（首个第一人称拓扑变化基准）代表"为特定能力缺口造数据"的思路；而 RGB-D SLAM on the Edge 在 Raspberry Pi 5 上对 RTAB-Map / ORB-SLAM3 做阶段级与函数级剖析，则提醒社区：边缘部署的实际瓶颈（如 RTAB-Map 无界工作内存导致的位姿图优化开销）与算法论文关注点往往错位。

### 技术路线观察

- **几何基础模型（Kosmo-GFM、V-JEPA 特征重建）：** 路线分歧明显。Kosmo-GFM 走"多任务预测 + 几何优化引擎 + 重建派生自监督"的系统集成路线，强调生产可用与下游 Gaussian Splatting 兼容；V-JEPA 特征重建走"复用视频预训练表征 + 极线传输 + 残差点图"的模块化消融路线，其结论更具警示性——相机回归策略与深度精度存在竞争关系，单纯替换骨干未必获益。两者共同暴露的空白是：几何基础模型的评测仍高度依赖少数基准（SpatialBench、CO3D、TUM），跨数据集的鲁棒性证据不足。

- **3D/4D 重建（ReCan-GS、Topo-4DGS、ThermalSplat、Track4D）：** 技术侧重从"表示能力"转向"失效模式治理"。ReCan-GS 与 Topo-4DGS 都在高斯层面做选择性激活/剪枝，但依据不同：前者用形变场 Jacobian 作为歧义代理，后者用部件级独立刚性变换 + 时变表面支撑；前者面向干扰物/烟雾等非合作观测，后者面向物体拓扑事件。ThermalSplat 走前馈泛化路线（soft census loss + boundary structure loss），摆脱逐场景优化与 RGB 引导；Track4D 则把 3D 跟踪编码为类视频信号以复用冻结 VDM 骨干（LoRA + point map 条件化），并诚实报告 RTV 精度更高但 NCMV 更易学习、需要 2D 跟踪器后处理的权衡。

- **神经场景表示与渲染（TTB、MatrixSplat）：** 一个在模型层做"注意力到 MLP 的知识蒸馏"，一个在系统层做"顺序合成到矩阵并行的重写"。二者互补：TTB 解决 decoder-only 视图合成的推理成本，MatrixSplat 解决 3DGS 高维特征渲染的吞吐与内存。值得注意的是 MatrixSplat 明确针对多模态/语义增强 3DGS，与 Spatial Foundry 等多模态数据趋势形成供需呼应。

- **机器人/AR 应用（MOSAIC、VOKE、VINE、RUMI、单视角力—变形估计）：** 呈现"模块化增强而非端到端重训"的共同取向。MOSAIC 保留预训练 VLA 主干只加辅助任务与注意力监督；VOKE 的 PKM 可插在标准位姿估计器之后；VINE 把端到端失败归因于视角错配后改用监督式障碍图 + 经典规划器；RUMI 用 AR/触觉反馈提升采集质量。这与 SLAM on the Edge 的剖析结论一致：在真实硬件与真实任务上，可解释、可替换的模块往往比端到端更可控。但单视角力—变形估计的定量结果（留出 RMSE 1.857 N、R²=0.440）提示该子方向的建模精度仍有限。

- **横向观察：** 稀疏视图、无位姿、低纹理、拓扑变化、干扰物、力感知等"困难条件"正在被系统性地拆解为独立子问题；与此同时，边缘部署、内存上界、实时帧率等工程约束开始进入论文的一等目标。
